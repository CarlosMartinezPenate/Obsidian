# M2 — Maintenance 2 Establishment

## Objective

Establish a new **100 mL maintenance culture** for each of the five strains from the existing [[M1]] cultures.

**M1 → M2**

| Strain | M1 inoculum | Fresh F/2 | Final M2 |
|:---|---:|---:|---:|
| SSA01 | 20 mL | 80 mL | 100 mL |
| SSA02 | 20 mL | 80 mL | 100 mL |
| SSA03 | 20 mL | 80 mL | 100 mL |
| SSB01 | 20 mL | 80 mL | 100 mL |
| SSE01 | 20 mL | 80 mL | 100 mL |
| **Total** | **100 mL** | **400 mL** | **500 mL** |

---

## 1. Prepare fresh F/2

**Exact requirement:** 400 mL  
**Prepare:** 500 mL

Using [[F2 Medium Preparation]]:

**500 mL final 1× F/2 = 490 mL sterile ASW + 10 mL 50× F/2 stock**

### ASW for this preparation

Using [[ASW recipe]]:

For **490 mL ASW** at the current working ratio of **37.1 g/L**:

**Coral Pro = 0.490 L × 37.1 g/L = 18.18 g**

1. Prepare approximately **490 mL ASW** using **18.18 g Coral Pro** as the starting amount.
2. Mix until completely dissolved.
3. Bring to approximately 25°C.
4. Check salinity with refractometer.
5. Adjust to **32–34 ppt** if required.
6. Filter-sterilize through **0.22 µm**.
7. Aseptically add **10 mL 50× F/2 stock**.
8. Mix gently.

> [!IMPORTANT]
> The 50× F/2 stock contains vitamins. Add it **after ASW filtration**.  
> Do not autoclave the completed F/2 medium.

---

## 2. Prepare M2 vessels

Label five clean sterile culture vessels:

- `SSA01_M2_F2_20260927`
- `SSA02_M2_F2_20260927`
- `SSA03_M2_F2_20260927`
- `SSB01_M2_F2_20260927`
- `SSE01_M2_F2_20260927`

Add **80 mL fresh F/2** to each vessel.

---

## 3. Prepare M1 inoculum

Before transfer:

1. Observe and photograph each M1 culture **before resuspension**.
2. Record observations using [[Dinoflagellate Culture Observation Sheet]].
3. Gently resuspend each M1 culture using the same procedure between strains.
4. Avoid leaving settled/clumped material behind when taking the inoculum.

---

## 4. Inoculate M2

For each strain:

**80 mL fresh F/2 + 20 mL corresponding M1 = 100 mL M2**

Transfer aseptically:

```text
SSA01_M1 ──20 mL──> SSA01_M2
SSA02_M1 ──20 mL──> SSA02_M2
SSA03_M1 ──20 mL──> SSA03_M2
SSB01_M1 ──20 mL──> SSB01_M2
SSE01_M1 ──20 mL──> SSE01_M2
```

Gently mix after inoculation.

## 6. Incubation

Return M2 cultures to the established culture conditions:

- **Temperature:** 26°C
- **Photoperiod:** 16L:8D
- **Irradiance:** ~25 µmol photons m⁻² s⁻¹
- **Medium:** F/2 in ASW
- **Culture mode:** static

---

## 7. Monitoring

### Day 0
- photograph
- culture observations
- OD750
- cell count if available

### Day 3–4
- visual establishment check
- contamination check
- no unnecessary sampling

### Day 7
- photograph before resuspension
- culture observations
- OD750
- cytometry if available

### Then
- monitor approximately weekly
- avoid allowing M2 to become another high-density production culture

---

## M1 disposition

**Do not discard M1 yet.**

Retain the original M1 cultures until:

- [ ] M2 cultures show successful establishment
- [ ] all five strains remain healthy
- [ ] no obvious contamination is observed
- [ ] [[P1]] plate backup has been established
- [ ] P1 establishment has been confirmed

After these checkpoints, decide whether remaining M1 material should be used experimentally or retired.
